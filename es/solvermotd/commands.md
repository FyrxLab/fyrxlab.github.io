# Comandos y Permisos

SolverMOTD incluye un par de comandos sencillos para administrar el plugin dentro del juego o desde la consola.

## Comandos

### `/smotd reload`
- **Alias:** `/solvermotd reload`
- **Descripción:** Recarga en caliente el archivo `config.yml`. Tu nuevo MOTD y formatos de mensajes tendrán efecto instantáneamente sin necesidad de reiniciar el servidor.
- **Permiso:** `solvermotd.reload`

### `/smotd help`
- **Alias:** `/solvermotd help`
- **Descripción:** Muestra el menú de ayuda que contiene la lista de comandos disponibles.

## Permisos

| Nodo de Permiso | Por defecto | Descripción |
| :--- | :--- | :--- |
| `solvermotd.reload` | `op` | Permite al usuario ejecutar el comando `/smotd reload`. |
