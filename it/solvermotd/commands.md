# Comandi e Permessi

SolverMOTD include alcuni semplici comandi per gestire il plugin in-game o dalla console.

## Comandi

### `/smotd reload`
- **Alias:** `/solvermotd reload`
- **Descrizione:** Ricarica a caldo il file `config.yml`. Il tuo nuovo MOTD e i formati dei messaggi avranno effetto istantaneamente senza riavviare il server.
- **Permesso:** `solvermotd.reload`

### `/smotd help`
- **Alias:** `/solvermotd help`
- **Descrizione:** Mostra il menu di aiuto contenente l'elenco dei comandi disponibili.

## Permessi

| Nodo Permesso | Predefinito | Descrizione |
| :--- | :--- | :--- |
| `solvermotd.reload` | `op` | Permette all'utente di eseguire il comando `/smotd reload`. |
