# Texture Emissive

## Panoramica
I minerali di Phosphophyllite supportano texture emissive quando usati con OptiFine o pacchetti shader.

## File
- **Texture Base**: Texture complete del minerale con cristalli
  - `0011.png` - Minerale di Phosphophyllite
  - `0111.png` - Minerale di Deepslate Phosphophyllite

- **Livelli Emissivi**: Solo le porzioni di cristallo luminose
  - `phosphophyllite_ore_e.png` - Livello emissivo per il minerale normale
  - `deepslate_phosphophyllite_ore_e.png` - Livello emissivo per il minerale di deepslate

## Come Usarle

### Con OptiFine/Shader
Le texture emissive faranno automaticamente brillare a piena luminosità solo le porzioni di cristallo, mentre la pietra resta scura.

### Senza OptiFine/Shader
I minerali emettono un livello di luce 10 (redstone + 1), facendo brillare leggermente l'intero blocco.
