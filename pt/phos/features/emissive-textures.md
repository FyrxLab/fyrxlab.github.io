# Texturas Emissivas

## Visão Geral
Os minérios de Phosphophyllite suportam texturas emissivas quando usados com OptiFine ou pacotes de shader.

## Arquivos
- **Texturas Base**: Texturas completas do minério com cristais
  - `0011.png` - Minério de Phosphophyllite
  - `0111.png` - Minério de Deepslate Phosphophyllite

- **Camadas Emissivas**: Apenas as partes brilhantes de cristal
  - `phosphophyllite_ore_e.png` - Camada emissiva para o minério normal
  - `deepslate_phosphophyllite_ore_e.png` - Camada emissiva para o minério de deepslate

## Como Usar

### Com OptiFine/Shaders
As texturas emissivas farão automaticamente com que apenas as partes de cristal brilhem em brilho total, enquanto a pedra permanece escura.

### Sem OptiFine/Shaders
Os minérios emitem nível de luz 10 (redstone + 1), fazendo o bloco inteiro brilhar levemente.
