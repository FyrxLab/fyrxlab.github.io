# Comandos e Permissões

O SolverMOTD inclui alguns comandos simples para gerenciar o plugin no jogo ou pelo console.

## Comandos

### `/smotd reload`
- **Aliases:** `/solvermotd reload`
- **Descrição:** Recarrega a quente o arquivo `config.yml`. Seu novo MOTD e formatos de mensagem entram em vigor instantaneamente, sem reiniciar o servidor.
- **Permissão:** `solvermotd.reload`

### `/smotd help`
- **Aliases:** `/solvermotd help`
- **Descrição:** Exibe o menu de ajuda contendo a lista de comandos disponíveis.

## Permissões

| Nó de Permissão | Padrão | Descrição |
| :--- | :--- | :--- |
| `solvermotd.reload` | `op` | Permite que o usuário execute o comando `/smotd reload`. |
