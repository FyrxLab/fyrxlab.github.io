# Commands & Permissions

SolverMOTD includes a few simple commands for managing the plugin in-game or from the console.

## Commands

### `/smotd reload`
- **Aliases:** `/solvermotd reload`
- **Description:** Hot-reloads the `config.yml` file. Your new MOTD and message formats will take effect instantly without restarting the server.
- **Permission:** `solvermotd.reload`

### `/smotd help`
- **Aliases:** `/solvermotd help`
- **Description:** Displays the help menu containing the list of available commands.

## Permissions

| Permission Node | Default | Description |
| :--- | :--- | :--- |
| `solvermotd.reload` | `op` | Allows the user to execute the `/smotd reload` command. |
