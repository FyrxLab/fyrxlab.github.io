## Installation

1. Download the latest version from [Modrinth](https://modrinth.com/mod/noteblock). Since 1.2.0 it's **one jar for Fabric, Forge and NeoForge** — the same file works on all three.
2. Drop the `.jar` into your `mods/` folder. Client and server both need it, since it adds real items and sounds.
3. On **Fabric**, also install [Fabric API](https://modrinth.com/mod/fabric-api).
4. Launch the game. The discs are in the **Noteblock** creative tab and in **Tools & Utilities**.

## Compatibility

| Loader | Minecraft versions |
|--------|--------------------|
| Fabric | 1.18 – 26.3 (needs Fabric API) |
| Forge | 1.18 – 26.3 |
| NeoForge | 1.20.1 – 26.3 |

Older builds (0.1.x for Forge 1.12.2 and 1.19.2) are still on Modrinth, but they carry a different set of songs and are no longer updated.
